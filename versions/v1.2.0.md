## 本次更新

本次更新让拼音输入更灵活，并带来更丰富的词库。

- 全拼现在支持完整拼音与声母混合输入。例如，输入 `beijdax` 即可获得“北京大学”等候选。
- 扩充常用词和专业词汇，更多此前没有结果的拼音现在可以直接找到候选。
- 优化候选查询路径，在增加新输入方式的同时，保持原有全拼、简拼和五种双拼的输入习惯。
- 保留输入方案、个性化学习和后续词联想设置，升级后无需重新设置。

## 升级提示

请退出 KOReader，并用新压缩包中的整个 `pinyinime.koplugin/` 替换旧目录，不要合并零散文件。个人设置和学习数据保存在 `koreader/settings/chinesepinyin.lua`，正常覆盖插件目录不会删除它们。

安装完成后，请在 `设置 → 设备 → 键盘 → 拼音输入法` 核对版本 `v1.2.0`，并打开“运行状态与诊断”确认实际词库模式。

## 兼容性

- 混拼只在全拼模式自动生效，不需要新增设置。
- 纯全拼、简拼、显式分隔和五种双拼继续使用原有输入方式。
- 完整数据库无法打开或校验失败时，插件会自动回退到兼容词库。
- 插件只接管 KOReader 简体中文虚拟键盘；其他键盘布局不受影响。
