## 更新内容

- 基于 [Merpyzf 的 KOReader 拼音输入法项目](https://github.com/Merpyzf/pinyinime.koplugin) 持续改进；原作者及第三方材料的来源、许可证见仓库中的 `THIRD_PARTY_NOTICES.md` 和各许可证文件。
- 短按地球键在简体中文与英文键盘之间往返切换；长按仍打开 KOReader 的键盘布局选择。
- 英文键盘提供离线单词补全候选，点击候选即可补全当前词并插入空格；本地记录选词频率以调整排序。
- 保留中文拼音候选、全拼、简拼、混拼、整句输入、五种双拼方案和后续词联想。
- 修复英文键盘先于中文输入引擎初始化时，候选栏组件尚未加载导致英文候选无法出现的问题。英文候选界面错误不会再连带关闭中英切换。

## 安装与升级

1. 下载并解压本页提供的完整 ZIP。
2. 退出 KOReader，将包内的整个 `pinyinime.koplugin/` 文件夹复制到 `koreader/plugins/`，完整替换旧目录，不要把新文件合并进旧目录。
3. 安全弹出 Kindle 并重新启动 KOReader。
4. 在 `设置 → 设备 → 键盘 → 拼音输入法` 核对版本为 `v1.3.3`。

个人偏好和学习数据位于插件目录之外，正常替换不会删除它们。GitHub 源码树为控制克隆体积省略了两个大型预编译词库数据库；日常安装请使用此处的完整 ZIP。

## 重点验证

- 冷启动后先打开英文输入框（不先切中文），输入 `th`、`hel` 或 `book`，确认候选栏出现并可点选补全。
- 短按地球键在英文、简体中文之间多次切换，中文输入 `nihao` 并确认拼音候选可用。
- 检查密码、数字输入框不会显示英文补全。

## 兼容范围与支持

最低支持 KOReader v2025.10；兼容性说明见 [README](../README.md)。遇到异常请提供设备型号、KOReader 版本、插件版本和日志中与输入法有关的错误行；不要发送个人设置文件 `koreader/settings/chinesepinyin.lua`。
